# Claude Code Tray

Выпадающее окно Claude Code для Windows. Нажми **Ctrl+Alt+C** где угодно, и терминал выедет от панели задач. Нажми ещё раз, и он уедет обратно, а сессия продолжит работать.

[English version](README.md)

![Иллюстрация: окно Claude Code над панелью задач](docs/illustration.svg)

## Возможности

- **Показать и скрыть окно:** Ctrl+Alt+C или клик по значку в трее.
- **Голосовой ввод:** Ctrl+Alt+V открывает окно и включает голосовой ввод Windows (Win+H). Он слушает на языке текущей раскладки.
- **Плавная анимация:** выезд окна и звезда, в такт частоте экрана.
- **Напоминания:** повторяет звук, пока Claude ждёт, а окно скрыто (по желанию, см. ниже).
- **Ничего лишнего:** один файл на C#, без зависимостей.

## Что нужно

- Windows 11 (проверено только на ней)
- [Windows Terminal](https://aka.ms/terminal)
- Claude Code в `%USERPROFILE%\.local\bin\claude.exe` (туда ставит нативный установщик)

## Сборка и запуск

```powershell
.\build.ps1
.\ClaudeTray.exe
```

Скрипт использует компилятор C#, который уже есть в Windows, ставить ничего не нужно. Чтобы трей запускался при входе, нажми правой кнопкой на значок и выбери **Start with Windows**.

## Звуки напоминаний

1. Добавь содержимое `hooks.example.json` в `~/.claude/settings.json` и укажи путь к `ClaudeTray.exe`.
2. Положи `coin-quiet.wav` (ответ готов) и `notify-quiet.wav` (Claude ждёт тебя) в `~/.claude/sounds`.

Трей повторяет звук раз в минуту, не больше 30 раз, пока окно не откроют.

## Что стоит знать

- Новые сессии запускаются в папке пользователя.
- Панель голоса закрывается кликом по её крестику, безопасного способа в Windows нет. Курсор на мгновение туда переместится.
