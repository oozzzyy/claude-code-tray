# Claude Code Tray

Выпадающее окно Claude Code для Windows. Нажми **Ctrl+Alt+C** где угодно, и терминал выедет от панели задач. Нажми ещё раз, и он уедет обратно, а сессия продолжит работать.

[English version](README.md)

![Ctrl+Alt+C открывает окно Claude Code, повторное нажатие прячет его](docs/demo.gif)

**[Скачай ClaudeCodeTray-Setup.zip](https://github.com/oozzzyy/claude-code-tray/releases/latest/download/ClaudeCodeTray-Setup.zip)**, распакуй и дважды нажми на `install.cmd`. Больше ничего не нужно.

## Возможности

- **Показать и скрыть окно:** Ctrl+Alt+C или клик по значку в трее.
- **Голосовой ввод:** Ctrl+Alt+V открывает окно и включает голосовой ввод Windows (Win+H). Он слушает на языке текущей раскладки.
- **Плавная анимация:** выезд окна и звезда, в такт частоте экрана.
- **Напоминания:** повторяет звук, пока Claude ждёт, а окно скрыто (по желанию, см. ниже).
- **Ничего лишнего:** один файл на C#, без зависимостей.

## Что нужно

- Windows 11 (проверено только на ней)
- [Windows Terminal](https://aka.ms/terminal) (установщик поставит его сам, если нет)
- Claude Code, из нативного установщика или доступный через PATH

## Установка

[Скачай архив](https://github.com/oozzzyy/claude-code-tray/releases/latest/download/ClaudeCodeTray-Setup.zip), распакуй его и дважды нажми на **install.cmd**. Запускать повторно безопасно. Установщик:

1. Проверяет Claude Code и Windows Terminal, а терминал при необходимости ставит через winget.
2. Собирает трей компилятором C#, который уже есть в Windows, и кладёт его в `%LOCALAPPDATA%\ClaudeCodeTray`.
3. Копирует звуки в `~/.claude/sounds`, не заменяя уже лежащие там файлы.
4. Добавляет хуки в `~/.claude/settings.json`, не трогая остальные настройки. Исходный файл один раз сохраняется как `settings.json.before-tray`. Хуки трея из другой папки переводятся на этот.
5. Включает автозапуск и запускает трей. Трей, уже запущенный из другой папки, закрывается, а его файлы остаются.

Чтобы заработали звуки, перезапусти открытые сессии Claude Code.

Чтобы убрать трей, автозапуск и хуки, запусти `install.cmd -Uninstall`. Файлы звуков останутся.

## Звуки напоминаний

Звук играет, когда ответ готов (`coin-quiet.wav`) и когда Claude ждёт тебя (`notify-quiet.wav`). Если окно остаётся скрытым, трей повторяет его раз в минуту, не больше 30 раз.

## Что стоит знать

- Новые сессии запускаются в папке пользователя.
- Панель голоса закрывается кликом по её крестику, безопасного способа в Windows нет. Курсор на мгновение туда переместится.
